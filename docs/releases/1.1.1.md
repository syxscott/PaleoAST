## PaleoAST 1.1.1

A scientific desktop application for palaeontological and ecological
statistics: ordination, group comparison, morphometrics, macroevolution,
time series and spatial analysis, with publication figures throughout.

### Install

Two formats, from the same build. Pick either.

**`PaleoAST-1.1.1-windows-x64.msi`** -- the normal choice. Double-click it,
choose the install folder, and PaleoAST appears in the Start Menu with a
shortcut. It installs to `C:\Program Files\PaleoAST`, can be repaired, and
removes itself cleanly on uninstall. A desktop icon is available but off by
default: choose *Advanced* and tick **Desktop shortcut**.

**`PaleoAST-1.1.1-windows-x64-portable.zip`** -- no installer. Unzip anywhere
and run PaleoAST.exe. The folder must stay together, because the exe loads its
libraries from the _internal subfolder beside it. Use this on a machine where
you cannot install software, or to keep several versions side by side.

Both ship the identical file tree. The MSI is not a separate build: it
packages the same `dist/PaleoAST` directory the zip was made from, so the
installer and the portable copy cannot drift apart.

Requires R (https://cran.r-project.org/) and ggplot2 for the R plotting
features. Everything else is self-contained.

**Upgrading from 1.1.0** -- run the 1.1.1 installer over the top. The two
share an Upgrade Code, so it replaces the old install in place and removes the
old files rather than leaving a second copy. If you want the earlier build
back afterwards, keep the 1.1.0 installer file; uninstalling 1.1.1 restores a
working 1.1.0.

## Thirteen analyses, and a way to reach all of them

*File > Run Analysis...* lists all 78 analyses in 12 categories. The
parameter form is generated from each analysis's own signature, so the
fields cannot drift from what the code accepts. 96.1% of the 304 parameters
in the catalog render automatically; the rest name their type and point at
the script console.

New, each verified against its reference implementation where one exists:

- **Group comparison** -- Mantel and partial Mantel tests. The partial form
  regresses both responses on the control before testing the residuals,
  which is the corrected version; permuting the raw vectors and applying
  the textbook formula is still the common implementation and is
  anti-conservative.
- **Clustering** -- k-means with an elbow curve, alongside the existing
  neighbour-joining and UPGMA.
- **Designs** -- two-way ANOVA with interaction, repeated-measures ANOVA,
  intraclass correlation, and contingency chi-square with Cramer's V.
- **Growth** -- von Bertalanffy, Gompertz, Michaelis-Menten, logistic,
  Gaussian growth curve and sinusoidal, fitted together and ranked by AICc.
- **Time series** -- autocorrelation with Bartlett bands, AR(1)
  prewhitening, REDFIT, multitaper spectral estimation, cross-correlation,
  autoassociation, Mann-Kendall with Sen's slope, runs test, and a
  Milankovitch forcing table.
- **Spatial** -- Moran's I, grid interpolation, nearest-neighbour point
  pattern statistics, and spherical statistics.
- **Ordination** -- detrended correspondence analysis.

## Scripting

*File > Script Console...* gives you Python against the current spreadsheet
and every registered analysis:

```
>>> analyses()                      # list everything runnable
>>> run("mantel", n_permutations=999)
>>> data.mean(axis=0)               # the live sheet, not a snapshot
```

`data` is a live view rather than a copy, so a script run after you edit a
cell sees the edit -- a snapshot would silently analyse numbers you had
already replaced.

The same session runs headless, for work that should not sit behind a
window:

```
paleoast-run analysis.py --data sites.csv --var n_permutations=999
```

`paleoast-run` is a console script, so it comes with a `pip install` of the
package rather than with the MSI or the portable zip -- those ship a
windowed executable and no command line. Everything it does, the in-app
console does too, including `data`, `analyses()` and `run()`.

## Two corrections that change published numbers

Both were wrong in the direction of looking plausible, which is why neither
showed up in ordinary use.

- **PERMANOVA's sums of squares did not sum to the total of the distance
  matrix it was given.** The divisors were `n - 1` and `n_g - 1` where the
  correct ones are `n` and `n_g`. Both terms were inflated, by different
  factors, so the error did not cancel: on the cross-validation fixture
  R-squared came out 0.8539 where `vegan::adonis2` gives 0.8636, and F
  81.83 against 88.67. Both are now exact. The permutation p-value would
  never have shown this -- scaling both terms leaves the permutation
  distribution's shape alone.
- **The Ricker wavelet scalogram reported periods 3.85x too small.** The
  transform was computed with the Mexican hat wavelet but its frequency
  axis was labelled with the Morlet Fourier factor, so a 385 kyr
  obliquity band came out labelled 100 kyr. Any cycle identification read
  off that plot was affected.

## The R plotting

R export of ordination plots. *File > "Export PCA as R Script"* writes an
editable ggplot2 script plus its data as a CSV. The script stands alone --
it needs R and ggplot2, not PaleoAST -- so it can be opened in RStudio,
edited, and re-run. "Re-run R Script" executes the file on disk without
ever regenerating it, and regenerating asks first if you have edited it.

R settings live in Preferences: Rscript path with a Detect button,
ggplot2 theme, base size, output format, timeout, and group colour
palette. The default is Okabe & Ito (2008) -- separable under
deuteranopia, protanopia and tritanopia, and in greyscale. ColorBrewer
Dark2, a greyscale set, and viridis are also selectable. A marker shape
varies with group as well, so classes stay separable in greyscale or when
there are more groups than colours.
